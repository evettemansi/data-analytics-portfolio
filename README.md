Aspiring Data Analyst with a B.S. in Software Engineering and hands-on experience using Power BI, Power Query, DAX, Excel, and GitHub. This portfolio features end-to-end analytics projects covering data cleaning, modeling, KPI development, visualization, validation, and business insight reporting.

## Featured Projects

### 1. [Retail Sales Analytics Dashboard](Projects/Retail-Sales-Dashboard)

- Analyzed **$2.56M in sales** and approximately **$638K in profit**.
- Cleaned and transformed sales data with Power Query.
- Built a star-schema data model and DAX measures for sales, profit, margin, order count, and average order value.
- Evaluated performance by category, subcategory, region, channel, customer segment, and customer.
- Created an interactive Power BI executive dashboard with KPI cards and business insights.

**Tools:** Power BI, Power Query, DAX, Excel

### 2. [HR Workforce Analytics Dashboard](Projects/HR-Analytics-Dashboard)

- Analyzed workforce trends covering 2,400 hires, 681 exits, and a current headcount of 1,719 employees.
- Cleaned and validated employee, department, and job-role data with Power Query.
- Built a relational model with a dedicated Date table and active/inactive date relationships.
- Developed DAX measures for headcount, hires, exits, workforce change, attrition, salary, and tenure.
- Created four report pages covering executive KPIs, attrition and retention, compensation and tenure, and workforce composition.
- Identified **1,719 active employees**, **681 exits**, an average active salary of **$79,310**, and an average active tenure of **2.7 years**.

**Tools:** Power BI, Power Query, DAX, Excel

### 3. [Customer Retention Analytics Dashboard](customer-retention-sql-power-bi)

* Audited 750 customer records in SQL Server and created a clean view containing 714 valid records.
* Checked customer-ID uniqueness, missing values, invalid dates, order logic, and revenue calculations.
* Developed DAX measures for repeat customers, churn risk, loyalty membership, satisfaction, orders, revenue, and net sales.
* Identified a 95.7% repeat-customer rate, a 16.2% churn-risk rate, and $361.6K in net sales.
* Built a two-page interactive Power BI dashboard with synchronized slicers and a high-risk customer priority table.

**Tools:** SQL Server, SSMS, Power BI, SQL, DAX

### 4. [Supply Chain Delivery Performance Analysis](supply-chain-delivery-performance/)

- Analyzed **99,092 orders** and **96,203 measurable deliveries** using SQL Server and Power BI.
- Cleaned and validated customer, order, product, seller, payment, review, and freight data through reusable SQL views.
- Built an order-level and item-level relational model with a dedicated Date table.
- Developed and validated delivery KPIs, including a **93.21% on-time delivery rate**, **12.48 average delivery days**, and **R$15.94M in revenue**.
- Identified delivery-risk patterns by month, customer state, product category, and seller, and measured the effect of late delivery on customer review scores.
- Analyzed **R$2.25M in freight costs** and identified product categories requiring cost and shipping-efficiency attention.

**Tools:** SQL Server, SSMS, Power BI, Power Query, DAX, GitHub
